# 考研任务与学习时长管理

一个面向考研备考的本地学习管理网页。项目使用原生 HTML、CSS 和 JavaScript 编写，不需要后端、不需要安装依赖，下载后直接打开 `index.html` 就能使用。

## 当前功能

- 每日目标
  - 添加、修改、删除今日任务
  - 设置任务名称、科目/项目、预计时长
  - 勾选任务完成状态
  - 任务自动保存到浏览器本地

- 学习计时
  - 支持数学、英语、专业课、政治、其他
  - 开始、暂停、继续、结束计时
  - 结束后自动生成学习记录
  - 可给单次计时添加备注

- 今日统计
  - 显示今天总学习时长
  - 显示今天各科累计学习时长

- 学习趋势
  - 支持查看近 7 / 14 / 30 天学习时长
  - 柱状图按科目分色显示当天时间分布
  - 统计日均时只计算有学习记录的日期
  - 天数较多时图表可横向滚动，并默认显示最近日期

- 历史记录
  - 按天汇总保存历史记录
  - 初始只显示日期、星期、各科时间和总时间
  - 展开后可查看当天具体学习记录和当天任务
  - 支持按科目筛选

- 学习总报
  - 显示全部记录的总学习时长
  - 显示累计记录天数
  - 显示每个科目的累计学习时长
  - 右侧显示月份日历热力图
  - 热力图颜色按 1.5 小时为一个档位
  - 支持切换月份查看历史热力图
  - 鼠标悬停日期 0.5 秒后显示当天总时长、各科时长和备注
  - 点击日期可打开当天学习总览
  - 日期总览包含任务完成情况、总时长、各科时间和当天备注
  - 当天备注可编辑并保存

- 考研倒计时
  - 可设置考试日期
  - 自动显示距离考试剩余天数

- 数据管理
  - 清空今日任务
  - 清空今日学习记录
  - 清空全部数据
  - 导出 JSON 文件用于备份

- 界面主题
  - 每天按星期自动切换主题
  - 使用高清背景图
  - 模块采用半透明玻璃风格

## 如何运行

方式一：直接打开

1. 下载项目文件。
2. 双击 `index.html`。
3. 用浏览器打开后即可使用。

方式二：使用本地静态服务

```bash
python3 -m http.server 4173
```

然后在浏览器访问：

```text
http://localhost:4173/index.html
```

## 数据保存说明

当前版本是纯前端本地网页，所有数据保存在浏览器的 `localStorage` 中，包括：

- 今日任务
- 学习计时记录
- 考试日期
- 每日备注

注意事项：

- 刷新网页后数据不会丢失。
- 同一个浏览器、同一个打开方式下可以继续使用原来的数据。
- 换浏览器、换设备、换域名后，看不到原来的本地数据。
- `file://` 打开和 `localhost` 打开属于不同存储空间，建议固定一种方式使用。

如需备份，可以点击页面中的“导出 JSON”。

## 关于云同步

当前版本没有后端和账号系统，因此暂不支持多设备实时同步。

如果后续要实现手机、平板、电脑同步，可以考虑接入：

- Firebase
- Supabase
- LeanCloud
- 自建后端接口
- GitHub Pages + 云数据库

## 部署到 GitHub Pages

如果已经上传到 GitHub，可以开启 GitHub Pages：

1. 进入仓库 `Settings`
2. 找到 `Pages`
3. Source 选择 `Deploy from a branch`
4. Branch 选择 `main` 和 `/root`
5. 保存后等待部署完成

部署完成后会得到一个公开访问链接，朋友可以直接用浏览器打开。

注意：即使部署到 GitHub Pages，数据仍然保存在每个用户自己的浏览器中，不会自动同步到云端。
