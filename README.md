# 考研任务与学习时长管理

一个用于考研备考的本地学习管理网页，使用原生 HTML、CSS 和 JavaScript 编写，无需后端、无需安装依赖，下载后直接打开即可使用。

## 功能

- 每日目标管理
  - 添加、修改、删除今日学习任务
  - 设置任务名称、科目/项目、预计时长
  - 勾选任务完成状态

- 学习计时
  - 支持数学、英语、专业课、政治、其他项目
  - 开始、暂停、继续、结束计时
  - 结束后自动生成学习记录

- 时长统计
  - 今日总学习时长
  - 今日各科目累计学习时长
  - 近 7 / 14 / 30 天学习趋势柱状图
  - 柱状图按科目分色显示时间分布

- 历史记录
  - 按天汇总展示
  - 默认显示日期、星期、各科时长、总时长
  - 展开后查看当天具体学习记录和任务情况

- 学习报告
  - 周报、月报、总报切换
  - 显示总学习时长、记录天数、分科目时长
  - 日历热力图展示学习强度

- 考研倒计时
  - 可设置考试日期
  - 自动显示距离考试剩余天数

- 数据管理
  - 清空今日任务
  - 清空今日学习记录
  - 清空全部数据
  - 导出 JSON 备份

- 界面主题
  - 按星期自动切换主题
  - 每天使用不同高清背景图
  - 半透明玻璃风格模块

## 如何运行

方式一：直接打开

1. 下载项目文件。
2. 双击 `index.html`。
3. 浏览器会自动打开网页。

方式二：使用本地静态服务

```bash
python3 -m http.server 4173
```

然后在浏览器访问：

```text
http://localhost:4173/index.html
```

## 数据保存说明

本项目目前是纯前端本地版本，数据保存在浏览器的 `localStorage` 中。

这意味着：

- 刷新页面后数据不会丢失。
- 同一个浏览器、同一个打开方式下可以继续使用原来的数据。
- 换浏览器、换设备、换域名后，看不到原来的本地数据。
- `file://` 打开和 `localhost` 打开属于不同存储空间，建议固定一种方式使用。

如果需要备份数据，可以点击页面中的“导出 JSON”。

## 关于云同步

当前版本不包含后端和账号系统，因此暂不支持多设备实时同步。

如果想在手机、平板、电脑之间同步数据，可以后续接入：

- Firebase
- Supabase
- LeanCloud
- 自建后端接口
- GitHub Pages + 云数据库

## 部署到 GitHub Pages

如果已经上传到 GitHub，可以开启 GitHub Pages：

1. 进入仓库 `Settings`
2. 找到 `Pages`
3. Source 选择 `Deploy from a branch`
4. Branch 选择 `main` 和 `/root`
5. 保存后等待部署完成

部署后会得到一个公开访问链接，朋友可以直接用浏览器打开。

注意：即使部署到 GitHub Pages，数据仍然保存在每个用户自己的浏览器里，不会自动同步到云端。
